# APOC Encounter Generator

APOC Survival — random encounter generator: d100 tables for every terrain, with full stat blocks and pictures on every roll.

- **Roller:** open `index.html` (or the GitHub Pages site) — pick a table, roll d100, get the encounter with its full stat block, picture, number appearing, source, and APOC note.
- **Tables:** 19 d100 tables — 11 terrains (Badlands, Plains, Forest, Hills, Mountains, Desert, Swamp/Marsh, River/Lake/Coast, Underground, Ruins, Bastion) plus road/trail, city, dungeon, deep-underground, ruins-interior, shoreline and open-water sub-tables. See `ENCOUNTER-TABLES.md`.
- **Stat blocks:** `STATBLOCKS.md` — full published blocks for the placed creatures, APOC adjustments kept separate.
- **Coverage & verification:** `COVERAGE.md` — sources, ecology audit, claimed/unclaimed undead lore, and verification results.
- **Data:** `encounters.json` is the machine-readable table set the roller uses.

APOC-screened throughout: no summoning or planar arrivals, Fog of Life surface-only, the Bastion's Melairshield bars undead/demons/dragons/flyers inside the walls, no drow or tiefling encounters, and dragons are a thousand-years-unseen legend — never rolled.
